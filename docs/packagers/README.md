# Packagers

How to add an app to FlatPark and keep it working. Read in this order:
[what a package is](basics.md) (the files, what runs when, and the extra-data
rule), [choosing a format](formats/README.md) and the page for the download you
picked, [prebuilt stacks](prebuilt.md) for libraries the runtime lacks, then
the [publishing guide](publishing.md) to build, test and open the
PR. The [packaging playbook](playbook.md) is the full process an agent follows
on every run.
